# Receipt Vault

A permanent, editable expense ledger that Claude fills in over MCP.
The app has **no AI inside**: no AI keys, no AI SDKs, zero dependencies. Claude (on the customer's own plan) reads the receipt photo; this app stores, edits, audits, summarises, and exports.

## Run locally
```bash
node server.js          # http://localhost:3000   (Node 18+)
node test.js            # end-to-end tests
```

## Deploy (about 10 minutes)
**Render (recommended):** push this folder to GitHub, then New > Blueprint, pick the repo. `render.yaml` sets up the service and a persistent disk. Add `DEMO_PASSWORD` in the dashboard.
The disk matters: without it the ledger resets on each deploy. Fly.io, Railway, and any VPS also work: run `node server.js` and mount a volume at `DATA_DIR`.

Env vars: `PORT` (auto), `DATA_DIR` (where vault.json lives), `BASE_URL` (optional, forces the public URL shown in the connector link), `DEMO_EMAIL` + `DEMO_PASSWORD` (seeds a test login).

## Connect to Claude
1. Open the live app and sign in (or create an account).
2. Copy your private connector link from the "Connect Claude" panel. It looks like `https://YOUR-APP/mcp/<secret>`.
3. Claude > Settings > Connectors > Add custom connector. Name: Receipt Vault. URL: the link. Save.
4. New chat, attach a receipt photo: "Add this to my Receipt Vault."

## MCP Tools (9 Tools)
- `add_expense`: Record a parsed receipt. Auto-detects line item math mismatches vs tips, guards against duplicates, and normalizes UK/US date formats and currency symbols (`£`, `$`, `€`).
- `list_expenses`: Search and filter ledger entries by keyword, date, category, review status, or policy flags.
- `update_expense`: In-place editing of fields on an existing record.
- `monthly_summary`: Totals spend, tax, net, and receipt count per currency with category breakdowns.
- `spending_insights`: High-level spend analytics, merchant rankings, and deductible VAT/GST tracking.
- `check_policy`: Pre-flight spend policy checks (meal caps, lodging caps, weekend spend, itemized alcohol).
- `batch_add_expenses`: Atomic bulk ingestion for multi-receipt processing in a single call.
- `tax_deduction_report`: Suggested tax treatment schedule (100% standard business, 50% meals write-off estimate, recoverable input tax credits for accountant review).
- `audit_anomalies`: Automated forensic audit detecting double-billing within 48h, split-receipt structuring to bypass procurement caps, weekend charges, and unverified math discrepancies.

## UI & Architecture
- **Primary Minimalist Ledger:** Clean, high-density financial table with instant inline editing, real-time KPI stats, and quick review toggles that finance teams trust.
- **Optional Visual Notice Board:** An optional tab displaying macOS-style monthly folder stacks and receipt slip previews.
- **Receipt Slips:** Lightweight SVG visual slip previews generated by Claude or direct image uploads, rendered securely via `<img>` tags with size caps to protect database integrity.
- **Audit & Policy Engine:** Automatically distinguishes between legitimate gratuity/tips and genuine calculation errors.
- **1-Click Accounting Exports:** Pre-formatted Reconciliation CSV and Standard CSV with spreadsheet formula injection protection.

## Pricing & Commercial Model
- **Free Tier:** Up to 50 receipts/month. Free and open source for personal or self-hosted use with zero subscriptions.
- **Pro Tier ($8/month):** Unlimited receipt volume, automated forensic audit anomaly detection, multi-currency tax treatment schedules, and priority support.

## Design Principles
- Auth for the MCP link is a per-user secret URL (simple, secure, zero-friction).
- Claude-created rows are flagged "needs review" until a person confirms or edits them in the ledger.
- `add_expense` rejects likely duplicates so a re-sent photo does not double-count.
- Tax reports provide suggested treatments and should be confirmed with a qualified CPA or accountant.
- Storage is a single JSON file with atomic writes. Swap to PostgreSQL when scaling beyond several hundred concurrent users.
